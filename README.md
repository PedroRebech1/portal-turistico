# Portal Turístico - Descubra o Brasil

Este é um projeto de um portal turístico interativo desenvolvido como avaliação da disciplina de Desenvolvimento Web (HTML + CSS). O objetivo do site é apresentar destinos, cultura e gastronomia brasileira para turistas nacionais e internacionais.
